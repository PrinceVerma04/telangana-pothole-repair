## Build
Any LaTeX distribution (MiKTeX, TeX Live). Run twice for the table of contents:

```
pdflatex main.tex
pdflatex main.tex
```

Overleaf: upload the zip as a new project; the compiler is pdfLaTeX and the main document is `main.tex`. The
diagrams are pre-rendered so the report compiles within the free plan's time limit (drawing them with TikZ on every
compile ran out of time there).

To change a diagram or chart, edit its source in `figures/src/` and rebuild that one figure (needs `pgfplots`):

```
cd figures/src
pdflatex -output-directory=.. fig-08-training-losses.tex
```

The log shows `ignored error: Infinite glue shrinkage found in box being split` where the two long tables break
across pages. It comes from the 2026 `longtable` package with wrapped cells, and it is harmless: the output is correct
and it is not counted as an error.
